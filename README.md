## About

I'm an Embedded Systems Development Engineer at Musashi Seimitsu Industry Co., Ltd., 
working in automotive R&D in Hamamatsu, Japan.

My work is about making mechanical systems controllable and measurable — bridging 
the gap between physical behavior and software logic. That means designing circuits 
that condition raw sensor signals into something a microcontroller can trust, writing 
firmware that responds predictably under real-world timing constraints, and validating 
that the full system — mechanical, electrical, and software — holds together.

I work across the stack: analog front-ends, real-time firmware, communication 
protocols, and system-level integration. The domain is automotive, so reliability 
and determinism aren't optional.

Outside of core work, I publish research and build side projects, usually around 
tooling and systems that I find genuinely useful.

If you want to discuss something or collaborate, reach out.
